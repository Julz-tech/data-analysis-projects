# Customer Segmentation Project

## Objective
Cluster customers based on purchasing behavior to inform marketing strategy and improve engagement.

## Dataset
- Source: E-commerce Customer Data
- Key columns: CustomerID, PurchaseHistory, TotalSpend, Frequency, Recency

## Tools & Libraries
- Python (pandas, scikit-learn)
- R (tidyverse, ggplot2)

## Steps Taken
1. **Data Cleaning & Preparation:**
   - Removed duplicates, normalized purchase metrics
   - Calculated RFM (Recency, Frequency, Monetary) scores
2. **Segmentation:**
   - Used K-Means clustering to identify customer segments
   - Evaluated cluster quality with silhouette scores
3. **Visualization:**
   - Plotted cluster distributions and segment profiles
   - Created summary charts for business stakeholders
4. **Insights & Recommendations:**
   - Identified high-value customers for VIP programs
   - Low-frequency segments targeted with retention campaigns

## Key Takeaways
- Applied clustering and RFM analysis to real business data.
- Learned to communicate segment insights clearly to non-technical stakeholders.
