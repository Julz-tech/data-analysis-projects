# Genomic Data Analysis Project

## Objective
Analyze genomic datasets to identify patterns in gene expression and explore biologically meaningful trends.

## Dataset
- Source: Public gene expression dataset
- Key columns: GeneID, SampleID, ExpressionLevel, Condition
- Format: CSV / TSV

## Tools & Libraries
- Python (pandas, numpy, matplotlib, Biopython)
- R (tidyverse, Bioconductor)

## Steps Taken
1. **Data Cleaning & Transformation:**
   - Normalized expression levels
   - Removed low-quality samples
   - Handled missing values
2. **Exploratory Analysis:**
   - Identified highly variable genes
   - Clustered samples based on gene expression patterns
3. **Visualization:**
   - Heatmaps of expression levels
   - PCA plots to visualize sample separation
   - Volcano plots for differential expression
4. **Insights & Recommendations:**
   - Discovered gene clusters associated with experimental conditions
   - Highlighted potential targets for further biological validation

## Key Takeaways
- Strengthened skills in genomic data analysis and cross-language workflow.
- Learned to combine Python and R for cleaning, visualization, and statistical analysis.
- Gained experience generating clear, actionable biological insights from large datasets.
